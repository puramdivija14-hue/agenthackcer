Free Daily Gmail Automation Guide (Google Apps Script)

Why this works: Regular browser notifications require your browser tab to be awake. By utilizing Google Apps Script (a free Google service included with every Gmail account), you can receive automated daily morning briefing emails at 7:30 AM IST with zero paid servers or API keys!

Step 1: Open Google Apps Script

Navigate to script.google.com and click on New Project.

Step 2: Copy and Paste the Script

Replace any placeholder code in Code.gs with the snippet below:

function sendDailyOpportunityBriefing() {
  var recipientEmail = Session.getActiveUser().getEmail();
  var today = new Date();
  
  // Format Date for India Standard Time
  var formattedDate = Utilities.formatDate(today, "Asia/Kolkata", "EEEE, dd MMMM yyyy");
  
  var emailSubject = "🎓 Daily Opportunity & Deadline Radar - " + formattedDate;
  
  // HTML Email Body
  var htmlBody = "<div style='font-family:sans-serif; max-width:600px; margin:auto; padding:20px; border:1px solid #E5E0D5; border-radius:12px; background:#FDFBF7;'>"
    + "<div style='background:#635BFF; color:#fff; padding:16px; border-radius:8px; text-align:center;'>"
    + "<h2 style='margin:0;'>Daily Student Deadline Radar</h2>"
    + "<p style='margin:4px 0 0;'>" + formattedDate + " (IST)</p>"
    + "</div>"
    + "<div style='padding:16px 0;'>"
    + "<p>Good morning! Here is your daily reminder to check your upcoming college submissions, Google certification tracks, and hackathon registrations.</p>"
    + "<div style='background:#FEF3C7; border-left:4px solid #F59E0B; padding:12px; margin:14px 0; border-radius:4px;'>"
    + "<strong style='color:#B45309;'>⚡ Action Step for Today:</strong><br>"
    + "Open your local <strong>Opportunity Reminder Agent</strong> to review deadlines closing within 7 days.</div>"
    + "<p style='font-size:13px; color:#6B7280;'>Sent automatically via Google Apps Script Time-driven trigger.</p>"
    + "</div></div>";
    
  MailApp.sendEmail({
    to: recipientEmail,
    subject: emailSubject,
    htmlBody: htmlBody
  });
  
  Logger.log("Briefing successfully dispatched to " + recipientEmail);
}

Step 3: Test and Authorize

Click the Run button at the top toolbar. Google will ask for permission to send emails from your own account to yourself. Grant authorization and verify that an email arrives in your Gmail inbox.

Step 4: Set the Daily 7:30 AM Trigger

  1. Click the Clock icon (Triggers) on the left panel.
  2. Click + Add Trigger (bottom right).
  3. Select Event source: Time-driven.
  4. Select Type of time based trigger: Day timer.
  5. Select Time of day: 7am to 8am.
  6. Click Save. You now have an automated daily reminder service!
